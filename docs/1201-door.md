# 12:01 Door 001

**Status:** experimental / non-canonical  
**Authority:** local specimen only  
**Purpose:** make the threshold between seeing and consequence executable without giving clocks, recommendations, or agents silent authority.

## Core distinction

```text
HIGH NOON = something becomes clear enough to witness

12:01 = an explicitly selected door is crossed
        and one bounded consequence becomes possible
```

12:01 is therefore a transition law, not a wall-clock claim.

A clock may display `12:01`. A scheduler may wake software at `12:01`.
Neither event grants crossing authority.

```text
CLOCK != GATE
RECOMMENDATION != SELECTION
DOOR != CROSSING
CROSSING != ACT
ACT != RECEIPT
```


Re-entry uses `reopenAfterReceipt()`. It preserves receipts, world revision,
and generation history while clearing local execution state. The next crossing
hatches a new generation. Re-entry is rebirth, not resurrection.

## Default capability horizon

Each proposed door becomes a bounded local capability horizon:

```text
root:                selected door
max depth:           2
write targets:       explicitly declared
action budget:       1
spawn budget:        0
promotion authority: false
```

The first specimen therefore cannot roam the graph, recursively create workers,
promote its result to source authority, or silently write somewhere adjacent.

## Falsifiable invariants

The tests require all of the following:

1. witnessing does not imply a door;
2. proposing a door does not select it;
3. selecting a door does not cross it;
4. a clock has no crossing authority;
5. crossing authority must name the selected door;
6. crossing hatches a new local ELF without itself changing the world;
7. the ELF may perform exactly one bounded act;
8. the act must target an explicitly writable location;
9. the act advances world revision exactly once;
10. the receipt preserves the crossing evidence and terminates the local ELF;
11. re-entry preserves history while the next crossing gets a new ELF generation.

## Why this sits beside Banana ELF Time

`banana-elf-time` tests cyclic work, Sabbath, Jubilee hold, release, and
generation changes. `twelve-oh-one` tests a different boundary: how a witnessed
possibility becomes one receipted local consequence.

They compose without collapsing into each other:

```text
Banana ELF Time  -> WHEN a local execution rhythm may pause/release
12:01 Door       -> HOW an explicitly selected possibility crosses into consequence
```

Neither module grants theological, calendar, institutional, or global authority.
